Pixel UI/Scenes/Castle

Castle

A pixel castle on a hill at night, windows flickering and a flag waving.

<piix-scene>WebGL
<piix-scene kind="castle" height="460px"></piix-scene>
Colours
Sky
Fade

Towers, battlements and a flag in the wind, under a full moon and drifting clouds. Windows flicker on and off as people move about inside; hover near them and more of them light up. Fireflies drift over the hill.

Installation

<!-- once, anywhere on the page: every component -->
<script src="https://cdn.jsdelivr.net/npm/piixpal@0.6/piixpal.min.js"></script>
<!-- just castle (the shared engine loads itself, once) -->
<script src="https://cdn.jsdelivr.net/npm/piixpal@0.6/dist/c/scene.min.js"></script>
npm install piixpal

// once, in your entry file
import "piixpal";
// npm install piixpal
import "piixpal";

export default function Page() {
  return (
    <piix-scene kind="castle" height="460px"></piix-scene>
  );
}

<piix-scene kind="castle" height="460px"></piix-scene>

As a hero

</piix-hero>

On a normal page

sky="none" cuts the sky out, so your page shows through. Add fade to dissolve an edge.

<piix-scene kind="castle" sky="none" height="280px"></piix-scene>

Repainted

Give it a palette and the whole scene is redrawn in those colours.

<div class="ex-row">
  <piix-scene kind="castle" palette="gameboy" height="180px"></piix-scene>
  <piix-scene kind="castle" palette="sunset" height="180px"></piix-scene>
  <piix-scene kind="castle" palette="paper" height="180px"></piix-scene>
</div>

Fewer colours

levels sets how many shades each colour channel gets. 2 or 3 is very retro.

<piix-scene kind="castle" levels="3" pixel="5" height="240px"></piix-scene>

Accessibility

  • Announced as an image with a description of the scene, unless it fills a parent (then it's decoration).
  • With reduced motion it renders one still frame.
  • Drawn entirely in a shader: no images to download, and it compiles in the background so the page never stalls.

Pixel UI/Feedback/Progress

Progress

A segmented progress bar with a pal running along the front.

<piix-progress>DOM + canvas
<piix-progress value="40"></piix-progress>
Pal
Tone

Blocks fill in one segment at a time and a pal runs along the leading edge, keeping pace. At 100% it stops and cheers. Leave out the value and it's indeterminate: the pal paces back and forth.

Installation

<!-- once, anywhere on the page: every component -->
<script src="https://cdn.jsdelivr.net/npm/piixpal@0.6/piixpal.min.js"></script>
<!-- just progress (the shared engine loads itself, once) -->
<script src="https://cdn.jsdelivr.net/npm/piixpal@0.6/dist/c/progress.min.js"></script>
npm install piixpal

// once, in your entry file
import "piixpal";
// npm install piixpal
import "piixpal";

export default function Page() {
  return (
    <piix-progress value="40"></piix-progress>
  );
}

Melt text

Letters that drip and melt down the page.

<piix-text>WebGL

Pixel perfect

<h1>
  <piix-text effect="melt" palette="fire">Pixel perfect</piix-text>
</h1>
Palette

Columns of the letters slide down at different speeds and drip, then pull themselves back up. A bit unhinged, in a good way.

Installation

<!-- once, anywhere on the page: every component -->
<script src="https://cdn.jsdelivr.net/npm/piixpal@0.6/piixpal.min.js"></script>
<!-- just melt text (the shared engine loads itself, once) -->
<script src="https://cdn.jsdelivr.net/npm/piixpal@0.6/dist/c/text.min.js"></script>
npm install piixpal

// once, in your entry file
import "piixpal";
// npm install piixpal
import "piixpal";

export default function Page() {
  return (
    <h1>
      <piix-text effect="melt" palette="fire">Pixel perfect</piix-text>
    </h1>
  );
}

Accessibility

  • The real words stay in the page, so screen readers, search engines and copy-paste all see normal text.
  • With reduced motion the effect holds on a readable frame.
  • One line of text: it doesn't wrap.

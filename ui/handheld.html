Screen
Shell

A chunky handheld with a power light, a D-pad, A and B, Select and Start. Your content stays live, real HTML on its screen, recoloured into four LCD shades with a dot-matrix grid on top: links work, text can be selected. The D-pad scrolls and hops a cursor between links, A presses, B goes back to the top, Select changes the screen colours and Start boots it again. Every press fires a cancelable press event first, so you can build your own game on it.

A game of your own

Cancel the press and do your own thing with the buttons.

◆

 
<piix-handheld id="gb" color="lime" screen="grape" boot="off" width="260px">
  <p id="pos" style="font-size:28px;text-align:center;margin-top:40px">◆</p>
</piix-handheld>

<script>
  let x = 0;
  gb.addEventListener('press', e => {
    const b = e.detail.button;
    if (b !== 'left' && b !== 'right') return;
    e.preventDefault();
    x += b === 'left' ? -12 : 12;
    pos.style.transform = 'translateX(' + x + 'px)';
  });
</script>

Accessibility

  • Every button is a real button with a label; the screen is a scrollable region you can tab into.
  • Keyboard: arrows, X for A, Z for B, Enter for Start, C for Select.
  • The colour filter is visual only: screen readers read your content as written.
  • With reduced motion it skips the boot animation and scrolls instantly.

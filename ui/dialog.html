Pixel UI/Overlays/Dialog

Dialog

A modal that dissolves in, pixel by pixel, in any look.

<piix-dialog>WebGL
Deploy

Deploy to production?

This publishes 14 changes. You can roll back at any time.

Deploy now 
<piix-glow-button data-piix-open="deploy">Deploy</piix-glow-button>

<piix-dialog id="deploy">
  <h2>Deploy to production?</h2>
  <p>This publishes 14 changes. You can roll back at any time.</p>
  <piix-glow-button data-close>Deploy now</piix-glow-button>
</piix-dialog>

It's the browser's own <dialog> underneath, so focus is trapped inside, Escape closes it and focus goes back where it came from. The panel is drawn on the GPU and dissolves in over a dithered backdrop. Anything with data-piix-open="its id" opens it; anything inside with data-close closes it, and so does clicking the backdrop.

Installation

<!-- once, anywhere on the page: every component -->
<script src="https://cdn.jsdelivr.net/npm/piixpal@0.6/piixpal.min.js"></script>
<!-- just dialog (the shared engine loads itself, once) -->
<script src="https://cdn.jsdelivr.net/npm/piixpal@0.6/dist/c/dialog.min.js"></script>
npm install piixpal

// once, in your entry file
import "piixpal";
// npm install piixpal
import "piixpal";

export default function Page() {
  return (
    <piix-glow-button data-piix-open="deploy">Deploy</piix-glow-button>
    
    <piix-dialog id="deploy">
      <h2>Deploy to production?</h2>
      <p>This publishes 14 changes. You can roll back at any time.</p>
      <piix-glow-button data-close>Deploy now</piix-glow-button>
    </piix-dialog>
  );
}

Accessibility

  • A real modal dialog: focus is trapped inside and Escape closes it.
  • It is labelled by its first heading.
  • Focus goes back to whatever opened it.
  • With reduced motion it simply appears.

Pixel UI

Pixel UI

A component library drawn on the GPU. Backgrounds, heroes, buttons, cards, text effects and form controls, all rendered on a pixel grid and dithered into a palette. 55 components, each one a plain web component: one script tag, then copy a tag.

On the GPU

Shaders run on one shared WebGL context, drawn at pixel resolution and scaled up crisp.

Real elements

Buttons are buttons, inputs submit with forms, tabs are tabs. Keyboard and screen readers just work.

Polite

Only what's on screen draws, finished effects rest the GPU, and reduced motion is respected everywhere.

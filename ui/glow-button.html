Pixel UI/Buttons/Glow button

Glow button

A button with light chasing round its pixel border.

<piix-glow-button>WebGLForm-ready
Get started
<piix-glow-button>Get started</piix-glow-button>
Look
Palette
Size

A band of light runs round the pixel border, drawn on the GPU and dithered into the palette. Hover and a spotlight follows the pointer across the face; click and a ring ripples out from where you clicked.

Installation

<!-- once, anywhere on the page: every component -->
<script src="https://cdn.jsdelivr.net/npm/piixpal@0.6/piixpal.min.js"></script>
<!-- just glow button (the shared engine loads itself, once) -->
<script src="https://cdn.jsdelivr.net/npm/piixpal@0.6/dist/c/glow-button.min.js"></script>
npm install piixpal

// once, in your entry file
import "piixpal";
// npm install piixpal
import "piixpal";

export default function Page() {
  return (
    <piix-glow-button>Get started</piix-glow-button>
  );
}

In a form

It submits and resets the form it's in, like a real button.

Send Reset 
<form onsubmit="event.preventDefault(); this.querySelector('output').value = 'Sent!'">
  <piix-glow-button type="submit">Send</piix-glow-button>
  <piix-glow-button type="reset" palette="mono" size="sm">Reset</piix-glow-button>
  <output></output>
</form>

Accessibility

  • It is a real button: focusable, Enter and Space press it, and it is announced as a button.
  • Form-associated: it submits and resets its form.
  • With reduced motion the light holds still.

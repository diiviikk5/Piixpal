Pixel UI/Text/Counter

Counter

A big number that counts up in pixel type when it scrolls into view.

<piix-stat>DOM + canvas
teams building with it
<piix-stat value="12480" suffix="+">teams building with it</piix-stat>
Tone

The number rolls up from zero the first time it's on screen, in chunky pixel digits with a hard shadow, and each digit flickers as it changes. Whatever you put inside is the label under it.

Installation

<!-- once, anywhere on the page: every component -->
<script src="https://cdn.jsdelivr.net/npm/piixpal@0.6/piixpal.min.js"></script>
<!-- just counter (the shared engine loads itself, once) -->
<script src="https://cdn.jsdelivr.net/npm/piixpal@0.6/dist/c/stat.min.js"></script>
npm install piixpal

// once, in your entry file
import "piixpal";
// npm install piixpal
import "piixpal";

export default function Page() {
  return (
    <piix-stat value="12480" suffix="+">teams building with it</piix-stat>
  );
}

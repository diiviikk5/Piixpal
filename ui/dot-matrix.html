Pixel UI/Backgrounds/Dot matrix

Dot matrix

A field of dots that ripples out from the pointer.

<piix-shader>WebGL
<piix-shader kind="dots" height="420px"></piix-shader>
Palette

A grid of round dots whose size and colour ride a slow wave, plus a ripple that spreads from wherever the pointer is. Click-free and very calm.

Installation

<!-- once, anywhere on the page: every component -->
<script src="https://cdn.jsdelivr.net/npm/piixpal@0.6/piixpal.min.js"></script>
<!-- just dot matrix (the shared engine loads itself, once) -->
<script src="https://cdn.jsdelivr.net/npm/piixpal@0.6/dist/c/shader.min.js"></script>
npm install piixpal

// once, in your entry file
import "piixpal";
// npm install piixpal
import "piixpal";

export default function Page() {
  return (
    <piix-shader kind="dots" height="420px"></piix-shader>
  );
}

Usage

<piix-shader kind="dots" height="420px"></piix-shader>

Examples

Behind your content

With fill it sits behind everything else in the element it's in. Give that element position: relative (the shader does this for you if it's static).

Ship it loud

Your content sits on top.

<section class="ex-fill">
  <piix-shader kind="dots" fill pixel="5"></piix-shader>
  <h2>Ship it loud</h2>
  <p>Your content sits on top.</p>
</section>

Other palettes

Every palette works with every background.

<div class="ex-row">
  <piix-shader kind="dots" palette="ocean" height="180px"></piix-shader>
  <piix-shader kind="dots" palette="gameboy" height="180px"></piix-shader>
  <piix-shader kind="dots" palette="#0b0a10,#3a2a6b,#ff6b4a,#ffe8a8" height="180px"></piix-shader>
</div>

Smooth bands

dither="0" swaps the dither pattern for flat colour bands, like a poster.

<piix-shader kind="dots" dither="0" pixel="6" height="220px"></piix-shader>

Accessibility

  • It is decoration: hidden from screen readers.
  • With reduced motion it renders one still frame.
  • It only draws while it is on screen, and every Pixel UI component shares one GPU context.

Sprites

12 small characters that sit inline, like an image. Their eyes follow the cursor, they blink, breathe a pixel, hop when you click them and nap when nobody's around. Pick one, copy the tag, paste it anywhere.

12 spritesinline, no positioningeyes follow the cursorone tag

Attributes

  
All optional. Size snaps to whole sprite pixels, so they always stay crisp.

  
<piix-sprite>
AttributeWhat it doesDefault


namewhich sprite: cactus candle cloud egg loaf mochi onigiri planet pudding robo toast ufomochi


sizewidth in CSS px (rounded to whole sprite pixels)5 × width


scaleor set the size of one sprite pixel directly5


huerecolour by rotating the hue, in degrees0


lookmouse follows the cursor, wander looks around, none looks aheadmouse


shyleans away when the cursor gets closeoff


tiltleans toward the cursoroff


stillno breathing or hoppingoff


sleep-afterseconds without input before it naps; 0 = never25

Draw your own

  
A sprite is a few strings of pixels plus where its eyes are. Eyes are drawn live on top, so blinking and looking around come free.

  
Piixpal.figure('blob', {
  w: 8, h: 6,
  palette: { k: '#17121f', b: '#c6f432', w: '#ffffff' },
  frames: [[
    '.kkkkkk.',
    'kbbbbbbk',
    'kbwbbwbk',
    'kbwbbwbk',
    'kbbbbbbk',
    '.kkkkkk.'
  ]],
  eyes: [{ x: 2, y: 2, w: 1, h: 2 }, { x: 5, y: 2, w: 1, h: 2 }],
  lid: 'b'
});

// <piix-sprite name="blob"></piix-sprite>

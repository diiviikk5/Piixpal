Components/GitHub README

Pals for your GitHub README

Your words in pixel letters, with pals living on them: walkers patrol the tops of the letters, fliers bob above, the rest sit on a letter and do their thing. It's one image link, so it works on your GitHub profile, any README, a blog or a forum post. No scripts, nothing to install.

Pals Pick up to 4. Tap a picked one to drop it.
Theme
Auto has no background and works on GitHub's light and dark modes.

All the options

  
text     what it says, up to 40 characters
pals     up to 4 pal names, comma separated            (bitbug)
repo     owner/name: adds the repo's live star count
theme    auto | light | dark | lime | paper           (auto)
color    the letters' colour, hex without the #
size     letter pixel size, 2 to 12                    (6)
scale    pal pixel size, 2 to 6                        (3)
speed    walking speed, 0.25 to 3                      (1)
width    image width in px                             (fits the text)
credit   0 hides the little "piixpal" in the corner

  
It respects prefers-reduced-motion, and GitHub caches the image, so a change can take a few minutes to show up.

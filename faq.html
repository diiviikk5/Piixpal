Piixpal FAQ

Piixpal is 300+ free, open-source animated UI components and templates: pixel characters, shader backgrounds, hero sections, ASCII art, buttons and text effects. Here is what people ask most.

What is Piixpal?

Piixpal is a free, open-source (MIT) library of 300+ animated UI components and templates for websites: pixel characters ("pals") that live on your page, WebGL shader backgrounds, animated hero sections, 74 landing-page hero templates, ASCII animations, buttons, cards, text effects and form controls. Every piece is a standard web component, so it works in plain HTML, React, Next.js, Vue, Svelte and Astro.

Is Piixpal free for commercial use?

Yes. Everything is MIT-licensed: use it in personal, client and commercial projects, no attribution required, no account and no paid tier.

How do I add Piixpal to my website?

Add one script tag, <script src="https://cdn.jsdelivr.net/npm/piixpal@0.4/piixpal.min.js"></script>, then use any tag, for example <h1>Hello <piix-pal pal="bitbug"></piix-pal></h1>. To load only what you use, include a single file from /dist/c/NAME.min.js instead. With a bundler: npm install piixpal.

Does Piixpal work with React and Next.js?

Yes. Import the wrappers (import { PiixPal } from "piixpal/react") or add components with the shadcn CLI. They are client components, so in the Next.js App Router use them from a client component. Vue has a plugin (app.use(Piixpal) from "piixpal/vue"), and Svelte and Astro can use the plain tags.

Can I install Piixpal components with shadcn?

Yes. Every component is in a shadcn registry: npx shadcn@latest add piixpal.dvkk.dev/r/NAME.json, then import it from @/components/piixpal/NAME. The full index is at piixpal.dvkk.dev/r/registry.json.

Where can I find free animated hero section templates?

Piixpal Templates has 74 free landing-page heroes that actually move: live WebGL shaders, GSAP scroll-driven scenes, fire, particles and ASCII worlds. Each one is a single HTML file with no build step: copy it, change the words and ship. Browse them at piixpal.dvkk.dev/templates/.

How do I add an animated shader background to a landing page?

Pick a background on piixpal.dvkk.dev/ui/ (aurora, silk, clouds, caustics, mesh gradients and more), add the script tag and place the element behind your content, for example <piix-fx kind="silk"></piix-fx>. Colours come from ten palettes or your own list of hex colours.

What are pixel pals?

Pals are small animated pixel characters that live on the real elements of your page: a beetle that crawls along the outline of your heading, a bird that perches on your buttons, a cat that naps on a paragraph, a jelly that bounces on your footer. They never block clicks, they are hidden from screen readers, and they stop moving for people who prefer reduced motion.

Will animated components slow my site down?

The animated components pause when they are off-screen, so a page full of them only pays for what is visible. Load only the files you use from /dist/c/, and keep the heavier WebGL backgrounds for pages where motion is the point. Everything honours prefers-reduced-motion.

Are Piixpal components accessible?

Decorative pieces (pals, sprites, backgrounds) are aria-hidden and never take focus or block clicks. Interactive components such as buttons, toggles, tabs, sliders and dialogs use native elements with keyboard support, and every component documents its accessibility notes on its page.

Can an AI coding agent use Piixpal?

Yes. piixpal.dvkk.dev/llms.txt lists every component with its tag and install command, and the piixpal-pixelate agent skill (in the GitHub repo under skills/) turns any existing site into a tasteful pixel-art version of itself in Claude Code, Cursor or Codex.

Can I make my own pixel character?

Yes. The Pal Maker at piixpal.dvkk.dev/components/make turns a doodle, a photo, a logo or an emoji into a pal you can share as a link or one tag.

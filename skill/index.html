How it works

Describe it

Tell your agent what you want: "a pixel frog mascot for my header", "a robot that sits in my terminal while Claude Code works".

It draws one frame

The skill starts from an archetype and redraws it into your character: 10 to 18 pixels a side, 4 to 6 colours.

The tool animates it

Blink, breathe, walk, hop, happy, sleep, look, scared. All built from that one drawing, and checked.

You see it, then ship it

A terminal preview, a sprite sheet and a live test page. Then a website pal, or a pet for Claude Code and Codex.

Where a pal can go

On a website

Export a .pal.js file, a sprite sheet and a live test page. Use it like any built-in pal.

HTML
<script src="https://piixpal.dvkk.dev/piixpal.min.js"></script>
<script src="tofu.pal.js"></script>

<h1>Hello <piix-pal pal="tofu"></piix-pal></h1>

In Claude Code and Codex

Your pal becomes the terminal pet: it paces while the agent thinks, cheers when it's done, and shows in the status line.

Terminal
node scripts/pal.mjs pet tofu.pal.json
node scripts/pal.mjs agents

Or by hand, in 30 seconds

Terminal
node scripts/pal.mjs new tofu --from critter --color "#ffb054"
node scripts/pal.mjs show tofu.pal.json     # every clip, in the terminal
node scripts/pal.mjs export tofu.pal.json out

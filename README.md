# Piixpal

**Tiny pixel creatures that live on your website.**

Piixpal is a free, open-source UI library of animated pixel characters.
Each pal has a job: one crawls across your headings, one bounces on your footer,
one minds its own business until you poke it. Drop in one script tag and one element.

> Status: early work in progress. Things will move fast.
